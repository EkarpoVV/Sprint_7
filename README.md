# Sprint_7
# Проект автоматизации тестирования приложения Самокат, бэкенд часть.
1. Основа для написания автотестов — фреймворк pytest.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v. 

# Проект состоит из четырех груп тестов 

test_creae_courier.py Проверяет создание курьера

test_create_order.py Проверяет создание заказа

test_login_courier.py Проверяет авторизацию курьера

test_order_list.py Проверяет список заказов курьера
